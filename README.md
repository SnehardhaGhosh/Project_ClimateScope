## 📌 Milestone Description
This repository contains **Milestone 1** of the **ClimateScope** project developed under the **Infosys Springboard Internship**.

## 📊 Dataset Description
### **GlobalWeatherRepository.csv**
Raw dataset containing global weather observations including:
- Temperature (°C)
- Humidity (%)
- Precipitation (mm)
- Wind Speed (km/h)
- Date and location attributes

### **GlobalWeatherCleaned.csv**
Processed dataset after:
- Handling missing values  
- Removing duplicates  
- Standardizing column names  
- Correcting data types  

### **MonthlyAggregateData.csv**
Derived dataset with:
- Monthly average temperature  
- Monthly rainfall totals  
- Monthly humidity and wind summaries

## 📈 Exploratory Data Analysis
EDA performed includes:
- Temperature and rainfall distribution analysis  
- Monthly and seasonal trend identification  
- Correlation between climate variables
