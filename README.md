## 📌 Milestone Overview
**Milestone 3** of the **ClimateScope** project focuses on the **development of a fully interactive climate analytics dashboard** using **Streamlit** and **Plotly**.

This milestone transforms the analytical insights and visualization designs from previous milestones into a **user-friendly, dynamic dashboard** that allows users to explore climate trends, KPIs, and patterns interactively.

---

## 🎯 Objectives
- Build an interactive dashboard using Streamlit  
- Implement dynamic visualizations using Plotly  
- Display key climate KPIs clearly and effectively  
- Enable user-driven filtering and exploration  
- Create an industry-ready data visualization application  

---

## 🧩 Key Features
- 📊 Interactive Plotly charts (line, bar, scatter, distributions)  
- 📌 KPI cards for climate indicators  
- 🔍 Filters for time periods and climate variables  
- 🌡️ Analysis of temperature, humidity, rainfall, and wind  
- 🎨 Custom dashboard styling using CSS  
- ⬇️ Download options for data and visuals  
- ⚡ Fast and responsive Streamlit UI

## 📊 Dataset Used
### **GlobalWeatherCleaned.csv**
The dashboard uses the cleaned climate dataset prepared in earlier milestones, containing:
- Temperature (°C)
- Humidity (%)
- Precipitation (mm)
- Wind Speed (km/h)
- Heat Index
- Wind Chill
- Time-based attributes

This dataset ensures **consistent and reliable analytics** across the dashboard.

---

## 📈 Dashboard Components
- **KPI Section**  
  Displays high-level climate metrics such as average temperature, total rainfall, and humidity levels.

- **Trend Analysis**  
  Time-series visualizations to analyze climate changes over time.

- **Comparative Analysis**  
  Interactive charts comparing multiple climate variables.

- **Distribution Analysis**  
  Histograms and scatter plots to study data spread and correlations.
