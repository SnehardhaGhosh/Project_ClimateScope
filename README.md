## 📊 Dataset Used
### **GlobalWeatherCleaned.csv**
This dataset contains structured and cleaned climate data including:
- Temperature (°C)
- Humidity (%)
- Precipitation (mm)
- Wind Speed (km/h)
- Derived climate metrics
- Time-based features

The dataset serves as the **single source of truth** for analysis and visualization in this milestone.

---

## 📈 Analysis & Visualization Design
Key analytical components include:
- Trend analysis of temperature and rainfall  
- Seasonal and monthly climate variations  
- Comparative analysis across climate parameters  
- Correlation analysis between weather variables  

Visualization design focuses on:
- KPI summary charts  
- Time-series plots  
- Distribution and comparative visuals  
- Dashboard-ready chart structures
